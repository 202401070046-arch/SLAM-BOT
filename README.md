SLAM Bot

An autonomous mobile robot project focused on Simultaneous Localization and Mapping (SLAM).

Overview:

The SLAM Bot project aims to develop a mobile robot capable of understanding its surroundings and estimating its position while building a map of the environment.

This repository contains the robot's source code, sensor integration, hardware documentation, testing results, and project development notes.

Objectives

- Develop a mobile robotic platform.
- Integrate sensors for environmental perception and motion estimation.
- Implement and test localization and mapping techniques.
- Integrate motor control and sensor data processing.
- Document the robot's development and testing.
